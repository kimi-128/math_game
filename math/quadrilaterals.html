개념 직사각형이란? p.166
📐 네 내각의 크기가 모두 같은 사각형을 직사각형이라고 합니다. 네 내각의 크기의 합은 360°이므로 네 내각은 각각 90°입니다.
직사각형은 네 내각이 90°로 같으므로 두 쌍의 대각의 크기가 각각 같습니다. 즉, 직사각형은 평행사변형의 특수한 경우이므로 평행사변형의 성질(두 쌍의 대변의 길이가 각각 같다, 두 대각선이 서로 다른 것을 이등분한다)을 모두 그대로 가집니다.
탐구 1 직사각형의 대각선은 어떤 성질이 있을까? p.166
📏 일정한 간격으로 점이 있는 모눈종이 위에 직사각형을 그리고, 두 대각선을 그어 길이를 재어 비교해 봅시다.
준비물: 자, 컴퍼스
1단계 · 네 내각이 모두 직각인 직사각형 ABCD를 그려요
📝 문제
❶ 직사각형의 두 대각선 AC, BD의 길이를 자로 재어 비교해 봅시다.
❷ 다른 친구가 그린 직사각형에서도 같은 결과가 나오는지 확인해 봅시다.
  1. 자로 재어 보면 AC = BD로 두 대각선의 길이가 같습니다.
  2. 다른 친구가 그린 직사각형에서도 두 대각선의 길이는 항상 같습니다.
직사각형의 두 대각선은 길이가 서로 같아요!
증명 직사각형의 대각선의 성질 p.166
직사각형의 두 대각선은 길이가 서로 같고, 서로 다른 것을 이등분한다.
✏️ 직사각형 ABCD에서 대각선 AC와 BD를 그으면
  1. △ABC와 △DCB에서 AB=DC, ∠ABC=∠DCB=90°, BC는 공통이므로 △ABC≡△DCB (SAS 합동)
  2. 합동인 도형의 대응변은 같으므로 AC=DB
  3. 또한 직사각형은 평행사변형이므로 두 대각선은 서로 다른 것을 이등분한다. 따라서 직사각형의 두 대각선은 길이가 서로 같고, 서로 다른 것을 이등분한다.
참고 (거꾸로 생각하면) 두 대각선의 길이가 서로 같고 서로 다른 것을 이등분하는 사각형은 직사각형입니다.

⑴ OC의 길이
⑵ ∠BCA의 크기
📝 문제 2
오른쪽 그림은 직사각형 ABCD 모양의 방패연이다. AC=100cm일 때, 다음을 구하시오. (단, 점 O는 두 대각선의 교점)
⑴ BD의 길이
⑵ OC의 길이
  1. 문제 1 ⑴ 직사각형의 두 대각선은 길이가 같으므로 AC=BD=14cm, OC = AC÷2 = 7cm
  2. 문제 1 ⑵ △ABC에서 ∠ABC=90°(직사각형), ∠BAC=40°이므로 ∠BCA=180°−90°−40°=50°
  3. 문제 2 ⑴ 직사각형의 두 대각선의 길이는 같으므로 BD=AC=100cm
  4. 문제 2 ⑵ 두 대각선은 서로 다른 것을 이등분하므로 OC = 100 ÷ 2 = 50cm
⑴ 7cm ⑵ 50° | ⑴ 100cm ⑵ 50cm
개념 마름모란? p.168
💎 네 변의 길이가 모두 같은 사각형을 마름모라고 합니다.
마름모는 네 변의 길이가 모두 같으므로 두 쌍의 대변의 길이가 각각 같습니다. 즉, 마름모도 평행사변형의 특수한 경우이므로 평행사변형의 성질(두 쌍의 대각의 크기가 각각 같다, 두 대각선이 서로 다른 것을 이등분한다)을 모두 그대로 가집니다.
탐구 2 마름모의 대각선은 어떤 성질이 있을까? p.168
✂️ 색종이를 반으로 접고 접은 선 위에 두 점 B, C를 표시한 다음, B와 C를 중심으로 반지름의 길이가 같은 원의 일부를 그려 교점 A를 표시하고, AB, AC를 따라 잘라 마름모를 만들어 봅시다.
준비물: 색종이, 가위, 자, 컴퍼스, 각도기
1단계 · 네 변의 길이가 모두 같은 마름모 ABCD를 만들어요
📝 문제
❶ 마름모 모양의 종이를 두 대각선을 따라 접으면 어떻게 겹쳐질까요?
❷ 두 대각선이 만나서 이루는 각의 크기는 몇 도일까요?
  1. 두 대각선을 따라 접으면 네 삼각형이 완전히 포개어집니다.
  2. 두 대각선이 만나서 생기는 각의 크기는 모두 90°입니다.
마름모의 두 대각선은 서로 다른 것을 수직이등분해요!
증명 마름모의 대각선의 성질 p.168
마름모의 두 대각선은 서로 다른 것을 수직이등분한다.
✏️ 마름모 ABCD에서 두 대각선 AC와 BD의 교점을 O라고 하면
  1. 마름모는 평행사변형이므로 두 대각선은 서로 다른 것을 이등분한다. 즉 OB=OD
  2. △ABO와 △ADO에서 OB=OD, AB=AD, AO는 공통이므로 △ABO≡△ADO (SSS 합동)
  3. 합동인 도형의 대응각은 같으므로 ∠AOB=∠AOD이고, ∠AOB+∠AOD=180°이므로 ∠AOB=∠AOD=90°, 즉 AC⊥BD
참고 (거꾸로 생각하면) 두 대각선이 서로 다른 것을 수직이등분하는 사각형은 마름모입니다.
문제 배우고 익히기 p.169
📝 문제 1
마름모 ABCD에서 두 대각선의 교점을 O라고 하자. ∠BAC=50°일 때, 다음을 구하시오.
⑴ ∠AOB의 크기
⑵ ∠BCA의 크기
📝 문제 2
한 변의 길이가 4cm인 마름모 ABCD에서 두 대각선의 길이가 각각 6cm, 8cm일 때, 다음을 구하시오.
⑴ 마름모 ABCD의 둘레의 길이
⑵ 마름모 ABCD의 넓이
  1. 문제 1 ⑴ 마름모의 두 대각선은 서로 수직이므로 ∠AOB=90°
  2. 문제 1 ⑵ 마름모는 네 변의 길이가 같으므로 AB=CB, 즉 △ABC는 이등변삼각형이다. 따라서 ∠BCA=∠BAC=50°
  3. 문제 2 ⑴ 마름모는 네 변의 길이가 모두 같으므로 둘레의 길이 = 4×4 = 16cm
  4. 문제 2 ⑵ 마름모의 넓이 = (두 대각선의 길이의 곱)÷2 = (6×8)÷2 = 24cm²
⑴ 90° ⑵ 50° | ⑴ 16cm ⑵ 24cm²
개념 정사각형이란? p.170
🔳 네 각의 크기가 모두 같고, 네 변의 길이가 모두 같은 사각형을 정사각형이라고 합니다.
정사각형은 네 내각의 크기가 모두 같으므로 직사각형이고, 네 변의 길이가 모두 같으므로 마름모입니다. 즉 정사각형은 직사각형이면서 동시에 마름모입니다.
직사각형
마름모
정사각형
정사각형의 두 대각선은 길이가 서로 같고, 서로 다른 것을 수직이등분한다.
헷갈리기 쉬운 부분 평행사변형은 옆으로 기울어진 모양, 직사각형은 가로로 긴 모양만 떠올려 정사각형은 직사각형이 아니라고 생각하거나 직사각형은 평행사변형이 아니라고 생각하기 쉽습니다. 모양이 아니라 사각형의 뜻과 성질로 판단해야 합니다.
개념 여러 가지 사각형 사이의 관계 pp.172~176
🗂️ 한 쌍의 대변이 평행한 사각형은 사다리꼴이고, 사다리꼴 중에서 다른 한 쌍의 대변도 평행한 사각형은 평행사변형입니다. 또 평행사변형 중에서 한 내각이 직각인 사각형은 직사각형, 이웃하는 두 변의 길이가 같은 사각형은 마름모이고, 직사각형이면서 동시에 마름모인 사각형은 정사각형입니다.
사각형
사다리꼴
↳ 한 쌍의 대변이 평행하다
평행사변형
↳ 다른 한 쌍의 대변도 평행하다
직사각형
↳ 한 내각이 직각이다
마름모
↳ 이웃하는 두 변의 길이가 같다
정사각형
직사각형이면서 마름모

⑴ 평행사변형은 사다리꼴이다. ( )
⑵ 직사각형은 마름모이다. ( )
⑶ 정사각형은 직사각형이면서 마름모이다. ( )
⑷ 마름모의 두 대각선의 길이는 항상 같다. ( )
⑸ 두 대각선이 서로 수직인 평행사변형은 마름모이다. ( )
⑹ 두 대각선의 길이가 서로 같고 서로 다른 것을 이등분하는 사각형은 직사각형이다. ( )
  1. ⑴ O 평행사변형은 두 쌍의 대변이 평행하므로, 한 쌍의 대변만 평행해도 되는 사다리꼴의 조건을 만족한다.
  2. ⑵ X 직사각형은 네 각의 크기가 같을 뿐, 네 변의 길이가 같다는 조건은 없다. (네 변까지 같으면 정사각형)
  3. ⑶ O 정사각형은 네 내각의 크기가 모두 같으므로 직사각형이고, 네 변의 길이가 모두 같으므로 마름모이다.
  4. ⑷ X 마름모는 두 대각선이 서로 수직이등분할 뿐, 길이가 같다는 보장은 없다. (길이까지 같으면 정사각형)
  5. ⑸ O 두 대각선이 서로 수직인 평행사변형은 이웃하는 두 변의 길이가 같아지므로 마름모이다.
  6. ⑹ O 두 대각선의 길이가 서로 같고 서로 다른 것을 이등분하는 사각형은 직사각형이 된다.
