개념 1 함수 (Function)
📖 정의 두 변수 x와 y에 대해
x의 값이 정해지면 y의 값이 오직 하나로 정해질 때,
"y는 x의 함수이다"라고 하고 y = f(x) 로 나타낸다.
  • 핵심 조건: x 하나에 y가 반드시 하나만 대응해야 함 (두 개 이상이면 함수가 아님)
  • 독립변수: 값을 자유롭게 정하는 변수 → x
  • 종속변수: x에 따라 결정되는 변수 → y
  • 표기: f(x), g(x), h(x) 등으로 씀
📋 함수 O / X 판별
대응 관계 함수? 이유
한 학생의 키 x → 몸무게 y✅ Ox 하나에 y 하나
자연수 x → x의 약수 y❌ X약수가 여러 개
변의 길이 x → 정사각형 넓이 y✅ Oy = x² 로 하나
넓이 x → 직사각형 가로 y❌ X가로 값이 여러 개
x의 한 값에 y의 값이 여러 개 대응되면 함수가 아니에요!
개념 2 함숫값 (Function Value)
📖 정의 함수 f(x)에서 x = a 일 때의 함수의 값을
f(a) 라고 쓰고, 이를 함숫값이라 한다.
f(a) = f(x)에서 x 대신 a를 대입한 값
① f(x) 식 확인
② x에 a 대입
③ 계산하여 답
📋 예제 f(x) = 3x − 2 일 때, 아래 함숫값을 구하시오.

구하는 값 대입 과정 답
f(1)3 × 1 − 2 = 3 − 21
f(3)3 × 3 − 2 = 9 − 27
f(−2)3 × (−2) − 2 = −6 − 2−8
f(0)3 × 0 − 2 = 0 − 2−2
✏️ 연습
f(x) = −2x + 5 일 때, f(4)와 f(−1)을 구하시오.
f(4) = −2 × 4 + 5 = −8 + 5 = −3
f(−1) = −2 × (−1) + 5 = 2 + 5 = 7
f(4) = −3  ,  f(−1) = 7
개념 3 일차함수 (Linear Function)
📖 정의 y = ax + b (a, b는 상수, a ≠ 0) 꼴로 나타낼 수 있을 때
"y는 x의 일차함수이다"라고 한다.
y = ax + b
🔺 기울기 (a) x가 1 증가할 때 y의 증가량
a = y의 증가량/x의 증가량
📍 y절편 (b) 그래프가 y축과 만나는 점의 y좌표
즉, x = 0 일 때의 y값 = b
  • 기울기 양수 (a > 0): 오른쪽 위로 올라가는 직선 ↗
  • 기울기 음수 (a < 0): 오른쪽 아래로 내려가는 직선 ↘
  • 기울기 절댓값이 클수록 더 가파른 직선
  • x절편 = −b/a  (y = 0 으로 놓고 x를 구한 값)
📋 예제: 기울기와 y절편 구하기
식 기울기 a y절편 b
y = 3x + 232
y = −½x − 4−½−4
y = x10
2y = 4x + 6→ y = 2x + 3 변환 후: 기울기 2, y절편 3
✏️ 연습
일차함수 y = −3x + 6 에 대해 답하시오.
① 기울기와 y절편을 구하시오.
② x절편을 구하시오.
③ f(2)의 값을 구하시오.
① 기울기 = −3  ,  y절편 = 6
② y = 0 대입: 0 = −3x + 6  →  3x = 6  →  x = 2
③ f(2) = −3 × 2 + 6 = −6 + 6 = 0
① 기울기 −3, y절편 6    ② x절편 2    ③ f(2) = 0
개념 4 일차함수와 연립방정식의 관계
📖 핵심 원리 연립방정식 { ax + by = c / dx + ey = f } 에서
각 방정식을 y = ... 꼴로 바꾸면 두 일차함수의 식이 된다.

✨ 연립방정식의 해 = 두 일차함수 그래프의 교점의 좌표 (x, y)
경우 1 — 해가 하나
두 직선이 한 점에서 교차
→ 해가 1개 존재
경우 2 — 해가 없음
두 직선이 평행 (기울기 같고 y절편 다름)
→ 해가 없음
경우 3 — 해가 무수히 많음
두 직선이 완전히 일치 (기울기, y절편 모두 같음)
→ 해가 무수히 많음
📋 경우 비교표
그래프 모양 기울기 y절편 해의 개수
한 점에서 교차다르다—1개
평행 (만나지 않음)같다다르다없음
완전히 일치같다같다무수히 많음
📋 예제: 연립방정식을 그래프로 풀기 연립방정식 { y = x + 1 / y = −x + 3 } 의 해를 구하시오.

① 두 식을 그래프로
② 교점의 좌표 찾기
③ 해 확인
두 직선 y = x + 1 과 y = −x + 3 의 교점 = (1, 2)
→ 연립방정식의 해: x = 1, y = 2
✏️ 연습
연립방정식 { y = 2x − 1 / y = −x + 5 } 의 해를 구하시오.
두 식을 연립:
2x − 1 = −x + 5
3x = 6
x = 2  →  y = 2 × 2 − 1 = 3

교점의 좌표: (2, 3)
x = 2, y = 3
📌 핵심 정리
연립방정식의 해 = 두 직선의 교점 좌표
교점이 1개 → 해 1개  |  평행 → 해 없음  |  일치 → 해 무수히 많음
각 방정식을 y = ax + b 꼴로 변형한 뒤 그래프 관계를 파악하자
