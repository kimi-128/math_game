심화 1 함수의 조건 심층 탐구
🔍 핵심 원리 함수의 핵심은 일대일 대응이 아니라 일대다 금지다.
x 하나에 y가 여러 개 → 함수 ✗
y 하나에 x가 여러 개 → 함수 ✓ (허용됨!)
📌 그래프로 판별하는 방법 — 수직선 검사 그래프 위에 수직선(세로선)을 그었을 때 교점이 항상 1개 이하이면 함수.
교점이 2개 이상인 x가 존재하면 함수가 아님.
📝 문제
기본
다음 중 y가 x의 함수인 것을 모두 고르시오.
① x의 배수 y   ② x보다 작은 자연수 y   ③ x의 제곱 y   ④ x의 역수 y   ⑤ x의 소인수 y
① x=2이면 배수가 2,4,6,… → 함수 아님
② x=5이면 1,2,3,4 → 함수 아님
③ x 하나에 y=x² 하나 → 함수 ✓
④ x≠0이면 y=1/x 하나 → 함수 ✓
⑤ x=12이면 소인수가 2,3 → 함수 아님
③, ④
심화
함수 f(x)에 대해 다음 조건이 성립할 때, 이 함수가 함수가 될 수 있는지 판단하고 이유를 설명하시오.

• x = 1일 때 f(1) = 3
• x = 2일 때 f(2) = 3
• x = 3일 때 f(3) = 5
함수이다.

함수의 조건은 "x 하나에 y가 하나"이다.
• x=1 → y=3 (1개) ✓
• x=2 → y=3 (1개) ✓  (다른 x가 같은 y를 가지는 것은 허용!)
• x=3 → y=5 (1개) ✓

세 x값 모두 y가 정확히 하나씩 대응되므로 함수이다.
함수이다. y값이 겹쳐도 x→y가 각각 하나면 OK.
최고난도
자연수 x에 대해 y = x를 나누었을 때의 나머지가 3 이하인 수의 개수 라 하자.
예) x=7이면 7÷1=나머지0, 7÷2=나머지1, 7÷3=나머지1, 7÷4=나머지3, 7÷5=나머지2, 7÷6=나머지1, 7÷7=나머지0 → 나머지가 3 이하인 수: 7개 → y=7
이 대응이 함수인지 판단하고, x=4일 때 y값을 구하시오.
x가 정해지면, x로 나눌 수 있는 자연수는 1~x이고
각 나눗셈의 나머지는 오직 하나이므로 — y는 유일하게 정해진다. → 함수이다.

x=4일 때:
4÷1 = 나머지 0 (3 이하) ✓
4÷2 = 나머지 0 (3 이하) ✓
4÷3 = 나머지 1 (3 이하) ✓
4÷4 = 나머지 0 (3 이하) ✓
→ y = 4
함수이다. x=4일 때 y = 4
심화 2 함숫값 심화 — 식의 변형과 활용
🔍 핵심 테크닉 함숫값 문제의 핵심은 식 대입 → 정리 → 조건 활용 순서.
f(a) + f(b), f(a+b), f(2a) 처럼 변형된 식도 같은 원리로 풀린다.
📌 자주 쓰이는 패턴
패턴의미예 (f(x)=2x+1)
f(a) + f(b)각각 대입 후 합산f(1)+f(2) = 3+5 = 8
f(a+b)a+b를 한 번에 대입f(1+2) = f(3) = 7
2·f(a)함숫값에 2를 곱함2·f(2) = 2×5 = 10
f(a) = k방정식으로 a 구하기2a+1=9 → a=4
📝 문제
기본
f(x) = 4x − 3 일 때, 다음을 구하시오.
① f(−2)    ② f(0) + f(1)    ③ f(a) = 9 일 때 a의 값
① f(−2) = 4×(−2)−3 = −8−3 = −11
② f(0)=−3, f(1)=1 → f(0)+f(1) = −3+1 = −2
③ 4a−3=9 → 4a=12 → a = 3
① −11    ② −2    ③ a = 3
중급
f(x) = ax + b 이고 f(1) = 5, f(3) = 11 일 때, a와 b의 값을 구하고 f(10)을 구하시오.
f(1)=5, f(3)=11을 각각 a, b에 대한 식으로 놓으면 연립방정식이 만들어져요.
f(1) = a + b = 5   ···①
f(3) = 3a + b = 11   ···②
②−① : 2a = 6 → a = 3
①에 대입: 3 + b = 5 → b = 2

f(x) = 3x + 2 이므로
f(10) = 3×10 + 2 = 32
a=3, b=2, f(10) = 32
심화
두 함수 f(x) = 3x + 1, g(x) = −x + 9 에 대해 f(a) = g(a)인 a의 값을 구하고, 그 때의 함숫값을 구하시오.
f(a) = g(a)는 두 함수의 값이 같아지는 x 를 찾는 문제예요.
f(a) = g(a) 이므로
3a + 1 = −a + 9
4a = 8
a = 2

함숫값: f(2) = 3×2+1 = 7  (g(2) = −2+9 = 7 으로 확인 ✓)
a = 2, 공통 함숫값 = 7
최고난도
f(x+1) = 2x + 5 일 때, f(x)를 구하고 f(7)의 값을 구하시오.
x+1 = t 로 치환하면 x = t−1. 이걸 식에 대입해보세요.
x+1 = t 로 놓으면 x = t−1
f(t) = 2(t−1) + 5 = 2t − 2 + 5 = 2t + 3
따라서 f(x) = 2x + 3

f(7) = 2×7+3 = 17

검증: f(x+1) = 2(x+1)+3 = 2x+5 ✓
f(x) = 2x + 3, f(7) = 17
심화 3 일차함수 심화 — 그래프와 식의 관계
🔍 조건으로 식 구하기 — 4가지 경우
주어진 조건방법
기울기 a, y절편 by = ax + b 에 바로 대입
기울기 a, 한 점 (x₁, y₁)y − y₁ = a(x − x₁)
두 점 (x₁,y₁), (x₂,y₂)기울기 = (y₂−y₁)/(x₂−x₁) 먼저 구함
x절편 p, y절편 q두 점 (p,0), (0,q) 활용
📌 평행과 일치 조건 y = ax+b 와 y = cx+d 에서
• 평행: a = c 이고 b ≠ d
• 일치: a = c 이고 b = d
• 수직(직교): a × c = −1
📝 문제
기본
두 점 (1, 3)과 (3, 7)을 지나는 일차함수의 식을 구하시오.
기울기 = (7−3)/(3−1) = 4/2 = 2
y = 2x + b 에 (1, 3) 대입: 3 = 2+b → b = 1
y = 2x + 1
중급
일차함수 y = ax + 3 의 그래프가 점 (2, b)를 지나고, y = 2x + b 와 평행할 때 a, b의 값을 구하시오.
평행하면 기울기가 같아요. 먼저 a를 구하고 점 (2,b)를 대입하세요.
y = 2x+b 와 평행 → 기울기 같음 → a = 2
y = 2x+3 이 (2, b)를 지남 → b = 2×2+3 = 7
(y절편이 3 ≠ 7이므로 평행 조건도 만족 ✓)
a = 2, b = 7
중급
일차함수 y = −2x + k 의 x절편과 y절편의 합이 9일 때, k의 값을 구하시오.
x절편은 y=0, y절편은 x=0을 대입해서 구해요.
y절편: x=0 → y = k
x절편: 0 = −2x+k → x = k/2
합: k/2 + k = 9 → 3k/2 = 9 → k = 6
k = 6
심화
세 점 A(1, 2), B(3, 6), C(k, 10)이 한 직선 위에 있을 때, k의 값을 구하시오.
A, B를 지나는 직선의 식을 구한 뒤, C를 대입하세요.
A(1,2), B(3,6) → 기울기 = (6−2)/(3−1) = 2
y = 2x + b에 (1,2) 대입: b = 0 → y = 2x
C(k,10) 대입: 10 = 2k → k = 5
k = 5
최고난도
일차함수 y = (a−1)x + (2a+3) 의 그래프가 x축과 y축 모두 양의 방향을 가로지를 때 (즉, x절편 > 0, y절편 > 0, 기울기 > 0), a의 범위를 구하시오.
세 조건을 각각 부등식으로 표현한 뒤 모두 만족하는 a를 찾으세요.
기울기 > 0: a−1 > 0 → a > 1
y절편 > 0: 2a+3 > 0 → a > −3/2
x절편 > 0: 0 = (a−1)x+(2a+3) → x = −(2a+3)/(a−1) > 0
a > 1 이면 (a−1) > 0 → −(2a+3) > 0 → 2a+3 < 0 → a < −3/2
∴ a > 1 이면서 a < −3/2 는 불가능

다시 검토: 기울기 < 0인 경우도 확인해야 하나, 문제 조건(기울기 > 0)에서 이미 a > 1.
그런데 y절편 = 2a+3 > 0 (a > 1이면 항상 성립), x절편 = −(2a+3)/(a−1)은 a>1이면 음수.
→ 세 조건을 동시에 만족하는 a는 존재하지 않는다.
해 없음 — 기울기 > 0이면 x절편이 반드시 음수가 됨
심화 4 일차함수와 연립방정식 — 해의 개수 심화
🔍 해의 개수 판별 완전 정리 연립방정식 { a₁x + b₁y = c₁ / a₂x + b₂y = c₂ } 에서
각각 y = m₁x + n₁, y = m₂x + n₂ 로 변환하면:
해가 1개 (교점 1개)
m₁ ≠ m₂
기울기 다름 → 한 점에서 교차
a₁/a₂ ≠ b₁/b₂
해가 없음 (평행)
m₁ = m₂, n₁ ≠ n₂
기울기 같고 y절편 다름
a₁/a₂ = b₁/b₂ ≠ c₁/c₂
해가 무수히 많음 (일치)
m₁ = m₂, n₁ = n₂
기울기·절편 모두 같음
a₁/a₂ = b₁/b₂ = c₁/c₂
📝 문제
기본
다음 연립방정식의 해의 개수를 판별하시오.
① { 2x − y = 1 / 4x − 2y = 3 }     ② { x + 2y = 4 / 3x + 6y = 12 }
① 2x−y=1 → y=2x−1  /  4x−2y=3 → y=2x−3/2
기울기 같고(2=2) y절편 다름(−1 ≠ −3/2) → 해가 없음 (평행)

② x+2y=4 → y=−x/2+2  /  3x+6y=12 → y=−x/2+2
완전히 같음 → 해가 무수히 많음 (일치)
① 해 없음     ② 해 무수히 많음
중급
연립방정식 { ax + 3y = 6 / 2x − y = b } 의 해가 없으려면 a, b에 대한 조건을 구하시오.
두 직선이 평행 → 기울기 같고 y절편 달라야 해요.
ax+3y=6 → y = −(a/3)x + 2
2x−y=b → y = 2x − b
평행 조건: 기울기 같음 → −a/3 = 2 → a = −6
y절편 달라야 함: 2 ≠ −b → b ≠ −2
a = −6 이고 b ≠ −2
중급
일차함수 y = 2x + 1 과 y = −x + 7 의 그래프의 교점을 구하고, 그 점이 y = kx − 1 위에 있을 때 k의 값을 구하시오.
교점: 2x+1 = −x+7 → 3x=6 → x=2, y=5 → 교점 (2, 5)
(2,5)를 y=kx−1에 대입: 5 = 2k−1 → 2k=6 → k = 3
교점 (2, 5), k = 3
심화
연립방정식 { 2x + ay = 4 / bx + 3y = 6 } 의 해가 무수히 많을 때, ab의 값을 구하시오.
해가 무수히 많다 → 두 직선이 완전히 일치 → 계수비가 모두 같아요.
두 직선이 일치:
2/b = a/3 = 4/6 = 2/3
2/b = 2/3 → b = 3
a/3 = 2/3 → a = 2
ab = 2 × 3 = 6
ab = 6
최고난도
세 직선 y = 2x + 1, y = −x + 7, y = kx + 3 이 한 점에서 만날 때(삼선공점), k의 값을 구하시오.
먼저 두 직선의 교점을 구하고, 세 번째 직선도 그 점을 지나야 해요.
y=2x+1, y=−x+7 의 교점: 2x+1=−x+7 → x=2, y=5 → (2, 5)
y=kx+3 이 (2,5)를 지남: 5 = 2k+3 → 2k=2 → k = 1
k = 1
📌 연립방정식 해 판별 전략 정리
①두 방정식을 모두 y = mx + n 꼴로 변환
②기울기 비교 → 다르면 해 1개
③기울기 같으면 y절편 비교 → 다르면 해 없음 / 같으면 무수히 많음
④교점 좌표 = 연립방정식의 해 → 연립하여 x, y를 구하면 됨
