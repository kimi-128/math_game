탐구 1 수심과 압력 p.108
🤿 스쿠버 다이버가 바닷속으로 내려갑니다.
수심 x m에서의 압력을 y기압이라 할 때, 아래 표를 보고 일차함수의 식을 구해봅시다.
① 변수 정하기
② 함수의 식 구하기
③ 값 구하기
④ 확인하기
수심 x (m)010202730
압력 y (기압) 123?4
📝 문제
수심이 27 m일 때, 압력은 몇 기압인가요?
그래프에서 x = 27 인 점의 y값을 확인해보세요.
  1. 변수 설정: 독립변수 x = 수심(m), 종속변수 y = 압력(기압)
  2. 함수의 식: 10 m 마다 1기압씩 증가 → 기울기 = 0.1
    x = 0일 때 y = 1 → y절편 = 1
    ∴ y = 0.1x + 1
  3. 값 구하기: x = 27 대입
    y = 0.1 × 27 + 1 = 2.7 + 1 = 3.7
  4. 확인: 수심 10 m마다 1기압 증가 ✓
수심 27 m에서의 압력은 3.7기압
탐구 2 빗물통 문제 p.109 · 예제 3
🌧️ 빗물통에 물이 49 cm 높이만큼 차 있습니다.
펌프로 2분마다 6 cm씩 물을 빼냅니다.
펌프를 켠 지 x분 후 물의 높이를 y cm라 할 때…
시간 x (분)02468
높이 y (cm) 4943373125
y = −3x + 49
📝 문제
물의 높이가 10 cm가 되는 것은 몇 분 후인가요?
그래프의 파란 점선(y = 10)과 만나는 점의 x좌표를 찾아보세요.
  1. 변수 설정: 독립변수 x = 시간(분), 종속변수 y = 높이(cm)
  2. 함수의 식: 분당 3 cm 감소 → 기울기 = −3, y절편 = 49
    ∴ y = −3x + 49
  3. y = 10 대입:
    10 = −3x + 49 → 3x = 39 → x = 13
  4. 확인: y = −3 × 13 + 49 = −39 + 49 = 10 ✓
13분 후 물의 높이가 10 cm가 됩니다.
스스로 풀기 양초 문제 p.109
🕯️ 길이가 25 cm인 양초에 불을 붙이면 1분마다 0.3 cm씩 짧아집니다.
불을 붙인 지 x분 후 양초의 길이를 y cm라 합니다.
📝 문제
① 일차함수의 식을 구하세요.
② 양초의 길이가 10 cm가 되는 것은 몇 분 후인가요?
③ 양초가 완전히 타는 것은 몇 분 후인가요?
  1. ① 함수의 식: 분당 0.3 cm 감소 → 기울기 = −0.3, y절편 = 25
    ∴ y = −0.3x + 25
  2. ② y = 10 대입:
    10 = −0.3x + 25 → 0.3x = 15 → x = 50분
  3. ③ y = 0 대입 (다 탈 때):
    0 = −0.3x + 25 → 0.3x = 25 → x = 250 ÷ 3 ≈ 83.3분
y = −0.3x + 25  |  50분 후 10 cm  |  약 83분 후 소멸
심화 섭씨 ↔ 화씨 변환 p.110
🌡️ 화씨온도(F)와 섭씨온도(C) 사이에는 다음 관계가 있습니다.
아래 그래프에서 두 직선의 교점을 찾아보세요.
F =  9⁄5  × C + 32
📝 문제
① 섭씨 0°C는 화씨 몇 °F인가요?
② 섭씨 100°C(물의 끓는점)는 화씨 몇 °F인가요?
③ 화씨 77°F는 섭씨 몇 °C인가요?
④ 섭씨온도와 화씨온도가 같아지는 온도는 몇 도인가요?
  1. C = 0: F = 9/5 × 0 + 32 = 32°F  (물의 어는점)
  2. C = 100: F = 9/5 × 100 + 32 = 180 + 32 = 212°F  (물의 끓는점)
  3. F = 77: 77 = 9/5 × C + 32 → 9/5 × C = 45 → C = 45 × 5/9 = 25°C
  4. F = C로 놓으면: C = 9/5 × C + 32 → −4/5 × C = 32 → C = −40°
−40°에서 섭씨온도 = 화씨온도! 🌡️
